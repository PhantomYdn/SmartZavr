## 🎯 CAMPAIGN STRUCTURE

### Campaign Overview: 1 Search Campaign, 3 Ad Groups

Given the 30,000₽ budget, we'll focus on HIGH-INTENT, LOW-COST keywords to maximize conversions.

```
SmartZavr Math Tutoring
├── Ad Group 1: Exam Preparation (ОГЭ/ЕГЭ) - 50% budget
├── Ad Group 2: Budget Long-Tail Keywords - 35% budget
```

- Exam keywords = highest intent + urgent need = best conversion rates

### Implementation Code (Add to src/main.js)

```javascript
// Yandex Metrica goal tracking
function trackGoal(goalName) {
    if (typeof ym !== 'undefined') {
        ym(104701968, 'reachGoal', goalName);
        console.log('Goal tracked:', goalName);
    }
}

// Track contact form submission
document.getElementById('contact-form').addEventListener('submit', function() {
    trackGoal('contact_form_submit');
});

// Track callback form submission
document.getElementById('callback-form').addEventListener('submit', function() {
    trackGoal('callback_form_submit');
});

// Track phone clicks
document.querySelectorAll('a[href^="tel:"]').forEach(function(link) {
    link.addEventListener('click', function() {
        trackGoal('phone_click');
    });
});

// Track Telegram clicks
document.querySelectorAll('a[href*="t.me/AVmathematics"]').forEach(function(link) {
    link.addEventListener('click', function() {
        trackGoal('telegram_click');
    });
});

// Track pricing section view
const pricingSection = document.getElementById('pricing');
if (pricingSection) {
    const observer = new IntersectionObserver((entries) => {
        entries.forEach(entry => {
            if (entry.isIntersecting) {
                trackGoal('pricing_view');
                observer.unobserve(entry.target);
            }
        });
    });
    observer.observe(pricingSection);
}

// Track scroll depth
let scrollTracked = false;
window.addEventListener('scroll', function() {
    if (!scrollTracked) {
        const scrollPercent = (window.scrollY / (document.body.scrollHeight - window.innerHeight)) * 100;
        if (scrollPercent >= 80) {
            trackGoal('deep_engagement');
            scrollTracked = true;
        }
    }
});
```

## ⚠️ RED FLAGS & TROUBLESHOOTING

### Problem: High spend, few leads (CPL >1,500₽)

**Possible Causes:**
- Wrong keywords (too generic, low intent)
- Poor ad relevance
- Landing page issues
- Targeting too broad

**Solutions:**
□ Review search query report → add negative keywords
□ Pause broad match keywords
□ Focus budget on exact match only
□ Test new ad copy with stronger CTA
□ Check landing page load speed (<3s)
□ Verify Metrica goals are firing correctly

---

### Problem: Low impressions/clicks (Budget underspent)

**Possible Causes:**
- Bids too low
- Keywords too specific (low search volume)
- Geographic targeting too narrow
- Quality score issues

**Solutions:**
□ Increase max CPC by 30-50%
□ Add broader phrase match keywords
□ Expand geographic targeting to more regions
□ Improve ad quality score (better ad copy, relevance)
□ Check if ads are disapproved (review moderation)

---

### Problem: Good CTR, but no conversions

**Possible Causes:**
- Landing page not convincing
- Tracking not set up correctly
- Wrong audience (clicks from wrong intent)
- Phone/form not working

**Solutions:**
□ Test form functionality (on mobile + desktop)
□ Verify Metrica tracking code is working
□ Check page load speed (use PageSpeed Insights)
□ Add trust signals to landing page (testimonials, guarantees)
□ Test "Free Lesson" messaging more prominently
□ Add exit-intent popup with special offer

---

### Problem: High bounce rate (>70%)

**Possible Causes:**
- Ad-to-landing page mismatch
- Slow page load
- Mobile experience poor
- Price shock

**Solutions:**
□ Ensure ad copy matches landing page headline
□ Optimize images (WebP format)
□ Test mobile experience thoroughly
□ Highlight "First lesson FREE" earlier
□ Add progress indicator to form (reduce friction)

```
   → Make Telegram CTA as prominent as phone

6. Price transparency reduces friction
   → Show pricing in ads (your advantage)

   → Be aggressive with budgets during this time

   → Add 50+ negatives in first week (lots of info queries)
```
