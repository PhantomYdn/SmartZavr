## IMPORTANT NOTES:

1. Use PHRASE match negatives (default in Yandex)
2. Add negatives at CAMPAIGN level (applies to all ad groups)
3. Review search query report DAILY for first 2 weeks
4. Add 5-10 new negatives per day initially
5. Be careful with broad negatives (might block good traffic)

## Negative Keyword Implementation:

FORMAT FOR YANDEX DIRECT:
-keyword (phrase match)
-"keyword" (exact match)
-[keyword] (broad match)

RECOMMENDED FORMAT:
Use phrase match (-keyword) for most negatives
This will block "keyword" in any position in the query

## Weekly Review Process:

Week 1: Expect to add 50-100 negatives (lots of discovery)
Week 2-3: Add 20-30 negatives (refinement)
Week 4+: Add 10-15 negatives (maintenance)
